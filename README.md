# پیشنهاد هوشمند سبد خرید ووکامرس

افزونه‌ای فارسی و راست‌چین برای نمایش پیام موفقیت و پیشنهاد محصولات مکمل، بلافاصله پس از افزودن کالا به سبد خرید ووکامرس.

توسعه‌دهنده: [نیما شادمان](https://nimashadman.ir/)

## امکانات

- نمایش پاپ‌آپ تأیید بعد از افزودن کالا به سبد خرید
- پیشنهاد حداکثر ۶ محصول مکمل
- افزودن سریع محصولات ساده از داخل پاپ‌آپ
- هدایت محصولات متغیر به صفحه انتخاب گزینه‌ها
- تعریف محصولات مکمل به‌صورت اختصاصی برای هر محصول
- اتصال یک یا چند «دسته مکمل» به یک دسته کامل
- اولویت‌بندی هوشمند پیشنهادها
- طراحی فارسی، راست‌چین و واکنش‌گرا
- سازگاری با جریان AJAX قالب WoodMart
- حفظ پیام و مینی‌کارت خود قالب WoodMart

## نیازمندی‌ها

- وردپرس ۶.۲ یا جدیدتر
- ووکامرس
- PHP 7.4 یا جدیدتر

## نصب

1. فایل ZIP نسخه انتشار را دانلود کنید.
2. در مدیریت وردپرس وارد «افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه» شوید.
3. فایل ZIP را نصب و فعال کنید.
4. پس از به‌روزرسانی، کش سایت، قالب WoodMart و مرورگر را پاک کنید.

## انتخاب مکمل برای یک محصول

1. محصول موردنظر را ویرایش کنید.
2. در کادر «اطلاعات محصول»، زبانه «محصولات مکمل» را باز کنید.
3. محصولات دلخواه را جست‌وجو و انتخاب کنید.
4. محصول را ذخیره کنید.

## انتخاب مکمل برای یک دسته کامل

برای نمونه، می‌توانید دسته «ملزومات کفش» را به تمام محصولات دسته «کتونی» متصل کنید:

1. وارد «محصولات ← دسته‌بندی‌ها» شوید.
2. دسته «کتونی» را ویرایش کنید.
3. در بخش «دسته‌های مکمل»، دسته «ملزومات کفش» را انتخاب کنید.
4. تغییرات را ذخیره کنید.

از این پس محصولات موجود دسته «ملزومات کفش» برای همه کالاهای دسته «کتونی» پیشنهاد می‌شوند.

## ترتیب انتخاب پیشنهادها

افزونه اولین منبع دارای محصول را با ترتیب زیر استفاده می‌کند:

1. محصولات مکمل اختصاصی کالا
2. محصولات دسته‌های مکمل
3. محصولات Cross-sell ووکامرس
4. محصولات مرتبط ووکامرس

## سازگاری با WoodMart

افزونه فرآیند AJAX اختصاصی WoodMart را دست‌کاری نمی‌کند و پس از رویداد موفق افزودن به سبد، پاپ‌آپ پیشنهادها را نمایش می‌دهد. به این ترتیب پیام، مینی‌کارت و رفتار اصلی قالب حفظ می‌شود.

## توسعه

ساختار افزونه ساده است:

```text
wc-smart-cart-upsell/
├── assets/
│   ├── css/frontend.css
│   └── js/frontend.js
├── wc-smart-cart-upsell.php
├── readme.txt
└── uninstall.php
```

بررسی سریع فایل اصلی:

```bash
php -l wc-smart-cart-upsell.php
```
