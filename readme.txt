پس از افزودن هر کالا به سبد خرید، یک پنجره تأیید زیبا نمایش می‌دهد و محصولات مکمل را برای خرید سریع پیشنهاد می‌کند.

توسعه‌دهنده: نیما شادمان — https://nimashadman.ir/

== نصب ==
1. فایل ZIP افزونه را از بخش «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب و فعال کنید.
2. یکی از محصولات را ویرایش کنید.
3. در کادر «اطلاعات محصول»، زبانه «محصولات مکمل» را باز کنید.
4. اسپری، کفی یا محصولات دلخواه را جست‌وجو و انتخاب کنید و محصول را ذخیره کنید.
5. افزونه در صفحه محصول و صفحات فروشگاه، افزودن به سبد را به‌صورت AJAX مدیریت می‌کند.

== تعریف مکمل برای یک دسته کامل ==
1. به «محصولات ← دسته‌بندی‌ها» بروید.
2. دسته اصلی، مثلاً «کتونی»، را ویرایش کنید.
3. در بخش «دسته‌های مکمل»، دسته «ملزومات کفش» را انتخاب و ذخیره کنید.
4. از این پس محصولات موجود دسته ملزومات کفش برای تمام محصولات کتونی پیشنهاد می‌شوند.

ترتیب اولویت پیشنهادها: محصولات مکمل اختصاصی کالا، دسته‌های مکمل، Cross-sell ووکامرس و در نهایت محصولات مرتبط.

اگر برای یک کالا محصول مکمل تعیین نشده باشد، افزونه ابتدا Cross-sellهای ووکامرس و سپس محصولات مرتبط را نمایش می‌دهد.

== امکانات ==
* طراحی فارسی و راست‌چین
* سازگار با موبایل
* افزودن سریع محصولات ساده بدون بستن پنجره
* هدایت محصولات متغیر به صفحه انتخاب گزینه‌ها
* امکان انتخاب حداکثر ۶ پیشنهاد برای هر کالا
* امکان اتصال یک یا چند دسته مکمل به یک دسته کامل
* بستن با کلیک بیرون پنجره یا کلید Escape
